This GDD describes **AI Studio’s creation workflows**, as requested. It is a design document for a creative tool, not a specification for a separate sword-fighting game. The sword-draw jump is a reference acceptance scenario.

Status language is deliberate: **Available** means present in this codebase; **Verified** identifies a performed check; **Planned** identifies work that has not been implemented. A listed control is not evidence that a model obeyed it.
